\section{Lie Groups}

We will assume
the reader is familiar, with
the mathematical
concepts of a vector space, Group,
Algebra and Lie algebra.
For some background on those,
see the beginning chapters
of my book, complementary to this one, 
Bayesuvius Quantico ********%\cite{}
What we aim to
do in this section
is to describe
how Lie Groups
can be interpret 
using the
tools and language

\subsection{All tangent spaces are
isomorphic}


\begin{figure}[h!]
\centering
\includegraphics[width=3.5in]
{differ-geo/lie-group-manifold.png}
\caption{Pictorial representation of
the Lie Group manifold $G$.
All tangent spaces are identical 
copies of $T_e(G)=\ger{g}$
}
\label{fig-lie-group-man}
\end{figure}



$G=$ Lie group. This will be 
the manifold $M$
in the
differential geometry
interpretation.

$\ger{g}=$ Lie algebra for group $G$.

$e=$ identity of $G$

$T_e (G)=$ tangent space at point $e$. We will
equate $T_e(G)$ with $\ger{g}$

$T_g (G)=$ tangent space at point $g$

 

$\{E_\alp\}_{\alp=1}^n=$  generators of Lie algebra


\beq
g= \exp(t^\alp E_\alp)
\eeq
where $g\in G$, $t_\alp\in\RR$.



The various points $g$ of the manifold
are different, but the tangent spaces
$T_g(G)$ for  each $g\in G$ 
are identical copies of each other
(i.e., isomorphic).
Remember, when we speak of a Lie algebra
in a non-differential geometry context, 
the elements of the Lie Algebra
are not labelled by a point $g$. They
are just a set of matrices (if a matrix representation
is being used, which is almost always the case).
So we first spend a  lot of ink 
showing that we need only consider the tangent space
at $e$. 
Actually, because groups are non-Abelian (i.e.,
its elements don't commute in general),
when $M$ is a group $G$, one can define 
two isomorphic
tangent spaces at each $g\in G$, the left-invariant (LI)
tangent space $T^{LI}_g(G)$ and the right
invariant (RI) tangent space $T^{RI}_g(G)$.
We usually set $T_g(G)=T^{LI}_g(G)$
early on,
and ignore $T^{RI}_g(G)$ thereafter.
After we are finished expressing a 1-1 onto
map of the tangent vectors $\vecX_e$ at $e$ 
and the (Left Invariant) tangent vectors $\vecX_g$ at $g$, we will  
talk of tangent vectors $\vecX$ which are 
functions that map $g\mapsto T_g(G)$


{\bf Left and right translations by $g$}
\beq
L_g h = gh, \quad R_g h = hg
\eeq

{\bf Left invariant vector field (LIV)} is
a vector field $\vecX\in\ger{X}_{LIV}$ such that for all $g\in G$, $\vecX_{g}\in T_g (G)$
 is defined  from $\vecX_{e}\in  T_e(G)$, as follows.

Define a path $\gamma(\tau)\in G$ 
for $t>0$ such that

\beq
\gamma:[0,1]\rarrow G, \quad
\gamma(0)=e, \quad
\dotvec{\gamma}(0)=\vecX_{e}
\eeq

\beq
(dL_g)_e: T_e(G)\rarrow T_g(G)
,\quad
(dL_g)_e\vecX_{e}= \AT{\frac{d\;}{d\tau}}{\tau=0} g\gamma(\tau)
\label{eq-g-e-is-ge}
\eeq
Note that the path $\gamma(\tau)\in G$ is
arbitrary except for what it does in the
neighborhood of $e$.
Translation is
very different from parallel
transport which we will
discuss when we define
covariant derivatives.
For parallel transport 
you need to be able to
measure the angle
between a curve and a vector, 
which means you need a \qt{connection}.
After a LIV translation,
$\vecX_e$ and $\vecX_g$ need not
be parallel translations of each other.
The relative angle between them is indeterminate.
LIV translation 
$\vecX_e \mapsto \vecX_g$
is just one of many possible 1-1 onto maps
 $T_e(G)\rarrow T_g(G)$.



For a LIV $\vecX$, 
for all $g\in G$,
$\vecX_g$ is defined from $\vecX_e$ by

\beq
\vecX_g = (dL_g)_e\vecX_e
\eeq
We extend the $dL_g$ map to

\beq
(dL_g)_a
\vecX_{a} \eqdef
\vecX_{ga}
\eeq
so the path $h(\tau)$ is moved to $ah(h)$ before
taking the derivative. Note that the right side
is not $\vecX_{ag}=a\vecX_g$.
However, from Eq.(\ref{eq-g-e-is-ge}),
if matrix representation are allowed,
$(dL_g)_e$ acts like left multiplication by $g$

\beq
g\vecX_e= \vecX_g
\eeq
and we extend that to

\beq
g\vecX_a = \vecX_{ga}
\eeq

For a Lie group,\footnote{$\cong$ means isomorphic, i.e., there exists a 1-1 onto map between the two sets,
and operations are preserved too.} 

\begin{align}
T_e(G)&=  \{ \vecX_e=\dotvec{\gamma}(0)\mid
\text{$\gamma:[0,1]\rarrow G$ is a path with $\gamma(0)=e$} \}
\\
&= \{ \vecX_e(\xi)\mid \xi\}\quad \text{if the different
starting directions are parametrized by $\xi$}
\end{align}

$
\ger{X}_{LI}(G) = \{\vecX(\xi)\mid \xi\}
$
where $\vecX(\xi)$ maps every $g\in G$
to an element of $T_g(G)$.
\beq
\ger{g}=T_e(G)\cong \ger{X}_{LI}(G)
\eeq

Define 

\beq T^p_g(G)= \underbrace{T_g(G)\times\cdots\times T_g(G)}_{\text{$p$ copies}}
\eeq

For 
$\ul{\omega_a}:T^p_a(G)\rarrow \RR$
and $\vecX_a\in T^p_a(G)$,
define the following pullback


\beq
(L_g)^*_a(\ul{\omega_a}(\vecX_a))=
\ul{\omega_{ga}}((L_g)_a \vecX_a)=
\ul{\omega_{ga}}(\vecX_{ga})
\eeq

{\bf Left invariant p-forms (LIP)}
$\ul{\omega_a}$ satisfy

\beq
(L_g)^*_a(\ul{\omega_a}(\vecX_a))=
\ul{\omega_{ga}}(\vecX_{ga})=\ul{\omega_a}(\vecX_a)
\eeq
In particular, if $a=e$,

\beq
\ul{\omega_g}(\vecX_g)=\ul{\omega_e}(\vecX_e)
\label{eq-LI-p-form}
\eeq
Thus,  an LIP
is fully specified  by its value 
at each $\vecX_e\in \ger{g}$.
For LIP, we are fully
justified in dropping the $g$
subscripts and writing $\omega(\vecX)$ for both sides
of Eq.(\ref{eq-LI-p-form}).


For $\vecX_e, \vecY_e\in T_e(G) =\ger{g}$, let
$[\vecX_e, \vecY_e]$ stand for the Lie bracket, which is
assumed to be given. Then 
for any LI vector fields
$\vecX, \vecY\in \ger{X}_{LI}$,
define

\beq
[\vecX,  \vecY]_g
\eqdef
\underbrace{
(dL_g)_e
\underbrace{[\vecX_e, \vecY_e]}
_{\in T_e(G)}}_{\in T_g(G)}
\eeq
Note that we avoid using $[\vecX_g, \vecY_g]$
due to a technicality. $[\vecX_g, \vecY_g]$
contains only info about 
$\vecX$ and $\vecY$ at $g$,
not in the neighborhood 
of $g$. The later info 
is necessary to compute derivatives.

\subsection{Cartan-Maurer equation}
Let $G$ be a Lie group and $\ger{g}= T_e(G)$.
The {\bf Maurer-Cartan 1-form}
$\pform{\vtheta}{}$ is defined as 
follows.


\beq
\ul{\vtheta_g}: T_g(G)\rarrow T_e(G),\quad \vecX_g \mapsto (dL_{g^{-1}})_g\vecX_g = \vecX_e
\eeq
Note that $\ul{\vtheta_g}: T_g(G)\rarrow T_e(G)$
whereas $(dL_g)_e: T_e(G)\rarrow T_g(G)$.
Note that $\ul{\vtheta}$  is a 1-form whose image
is a tangent vector at $e$ (rather than a real number, like 
the usual 1-forms). That is the reason why
we have chosen to do both, underline it and give it a
vector sign. We have actually
encountered vector valued 1-forms before, in $\ul{d\vecr}$.

\begin{claim}
For any matrix $g(\tau)\in G$
\beq
d(g^{-1})=
-g^{-1}dg g^{-1}
\eeq

\beq
gd(g^{-1})=
-dg g^{-1}
\eeq
\end{claim}
\proof

\beq
0=d(g^{-1}g)=
d(g^{-1})g + g^{-1}dg
\eeq
\qed

\begin{claim}
For a matrix Lie group and $g\in G$,\footnote{Thus, informally, you can think of $\ul{\vec\theta}=dL_{g^{-1}}$
as equal to $L_{g^{-1}\ul{dg}}$.}

\beq
\ul{\vtheta}= g\ul{dg}
\eeq

\end{claim}
\proof

\beq
\ul{\vtheta}= (dL_{g^{-1}})_g
\eeq

\beq
\gamma:[0,1]\rarrow G, \quad
\gamma(1)=g,
\quad \dotvec{\gamma}(1)=\vecX_g
\eeq

\beq
(dL_{g^{-1}})_g\vecX_g=
g^{-1} \vecX_g\cdot \nabla
 \gamma(1)
= g^{-1}\ul{dg}(\vecX_g)
\eeq
\qed

Note that for ordinary 1-forms $\ul{\alp}=a \ul{dx}+
b\ul{dy}$
with scalar coefficients $a, b$,
it's always true that
$\ul{\alp}\wedge \ul{\alp}=0$. However,
$\ul{dg}$ is not an ordinary 1-form: it's a
1-form with matrix coefficients which don't commute in general.

\beq
\ul{dg}= A \ul{dx}+ B\ul{dy}
\eeq
so 
\beq
\ul{dg}\wedge \ul{dg}=
[A, B]\ul{dx}\wedge \ul{dy}
\eeq

What is $\ul{dg}$?

\beq
g = [g_{\mu, \nu}]^{n\times n}
\eeq

\beq
\ul{dg}=
[\ul{dg_{\mu, \nu}}]^{n\times n}
\eeq
so $\ul{dg}$ is an $n\times n$ matrix of 1-forms. If $\{\ul{dx}, \ul{dy}\}$
are a basis for the 1-forms in each entry
of $\ul{dg}$,
then

\beq
\ul{dg}=A\ul{dx}+ B\ul{dy}
\eeq
as assumed earlier.



Choose a basis $\{\vecE_\alp\}_{\alp=1}^n$ for $\ger{g}$. Assume

\beq 
[\vecE_\beta, \vecE_\gamma]= C\indices{^\alp_{\beta\gamma}}
\vecE_\alp
\eeq

Expand 

\beq
\pform{\vtheta}{}=
\pform{\theta^\alp}{}\vecE_\alp
\eeq

\beq
\ul{\theta^\alp}(\vecE_\beta)=
\delta^\alp_\beta
\eeq


\begin{claim}

\beq
\ul{d\theta^\alp}(\vecE_{\mu}, \vecE_\nu)=
-C\indices{^\alp_{\mu\nu}}
\eeq
\end{claim}
\proof


Let

\beq
\ul{\theta^\alp}=\ul{dx^j}\theta^\alp_j,\quad
\vecE_\beta = E^i_\beta \vecpder{x^i},
\eeq

\beq
\theta^\alp_i E^i_\beta=
\ul{\theta^\alp}(\vecE_\beta)=
\delta^\alp_\beta
\eeq

\beqa
\ul{d\theta^\alp}(\vecE_\mu, \vecE_\nu)&=&
\left[
\partial_i \theta^\alp_j
-
\partial_j\theta^\alp_i
\right]
\ul{dx^i}\wedge \ul{dx^j}
(\vecE_\mu, \vecE_\nu)
\\
&=&
\left[
\partial_i \theta^\alp_j
-
\partial_j\theta^\alp_i
\right]\ul{dx^i}(\vecE_\mu)\wedge \ul{dx^j}(\vecE_\nu)
\\
&=&
\left[
\partial_i \theta^\alp_j
-
\partial_j\theta^\alp_i
\right]E^i_\mu E^j_\nu
\\
&=&
\left\{
\begin{array}{l}
E^i_\mu\left[\partial_i
\cancel{[\ul{\theta^\alp}(\vecE_\nu)]}
-\theta_j^\alp\partial_i E^j_\nu
\right]
\\
- (i\mu\swap j\nu)
\end{array}
\right.
\\
&=&
-\theta^\alp_j E^i_\mu\partial_i E^j_\nu
+   \theta^\alp_i E^j_\nu\partial_j E^i_\mu
\\
&=&
-\theta_j^\alp
\left[
E^i_\mu\partial_i E^j_\nu
-
E^i_\nu\partial_i E^j_\mu
\right]
\\
&=&
-\theta^\alp_j
\left[
\oper{\vecE_\mu} E^j_\nu
-
\oper{\vecE_\nu} E_\mu^j
\right]\quad
(\text{Use
$E^i_\mu \partial_i = \oper{\vecE_\mu}$})
\\
&=&
-\theta^\alp_j
\left[
\oper{\vecE_\mu}, \oper{\vecE_\nu}
\right]\vecr_j
\\
&=&
-\theta^\alp_j 
[\vecE_\mu, \vecE_\nu]^j
\\
&=&
-C\indices{^\beta_{\mu\nu}}
\theta^\alp_j E^j_\beta
\\
&=&-
C\indices{^\beta_{\mu\nu}}
\delta^\alp_\beta
\\
&=&
-
C\indices{^\alp_{\mu\nu}}
\eeqa

\qed

\begin{claim}(Maurer-Cartan Equation)


\beq
\ul{d\vtheta} = -\;\frac{1}{2}
[\ul{\vtheta}, \ul{\vtheta}]
\eeq


\beq
\ul{d\theta^\alp}=-
C\indices{^\alp_{\mu\nu}}
\ul{\theta^\mu}
\wedge
\ul{\theta^\nu}
=
-\;\frac{1}{2}
C\indices{^\alp_{\mu\nu}}
[\ul{\theta^\mu}
,
\ul{\theta^\nu}]
\eeq
\end{claim}
\proof
\beq
\ul{d\theta^\alp}=
\left[
\partial_i \theta^\alp_j
-
\partial_j\theta^\alp_i
\right]
\ul{dx^i}\wedge \ul{dx^j}
\eeq

\beq
\ul{d\theta^\alp}=
\frac{1}{2}A\indices{^\alp_{\mu\nu}}
\ul{\theta^\mu}
\wedge \ul{\theta^\nu}
\eeq
Find $A\indices{^\alp_{\mu\nu}}$

\beq
\ul{\theta^\mu}\wedge\ul{\theta^\nu}(\vecE_\rho, \vecE_\s)=
\frac{1}{2}
(\delta^\mu_\rho\delta^\nu_\s
-
(\rho\swap \s))
\eeq

\beq
C\indices{^\alp_{\mu\nu}}
\ul{\theta^\mu}\wedge\ul{\theta^\nu}(\vecE_\rho, \vecE_\s)=C\indices{^\alp_{\rho\s}}
\eeq

\beq
\ul{d\theta^\alp}(\vecE_\rho, \vecE_\s)=
C\indices{^\alp_{\rho\s}}=
C\indices{^\alp_{\mu\nu}}
\ul{\theta^\mu}\wedge\ul{\theta^\nu}(\vecE_\rho, \vecE_\s)
\eeq



\beq
\ul{\theta^\mu}\wedge \ul{\theta^\nu}=
\frac{1}{2}\left[
\ul{\theta^\mu}, \ul{\theta^\nu}
\right]
\eeq

Second proof assuming $G$ has a matrix representation

Assume 

\beq
\ul{\vtheta} = g^{-1}\ul{dg}
\eeq
Then

\beq
\ul{d\theta}=
d(g^{-1}\ul{dg})
=
\ul{dg^{-1}}
\wedge \ul{dg}
\eeq

\beq
\ul{d(g^{-1})}=
-g^{-1}(\ul{dg})g^{-1}
\eeq

\beq
\ul{d\theta}=
-[g^{-1}\ul{dg}g^{-1}]\wedge \ul{dg}=-
[g^{-1}\ul{dg}]\wedge
[g^{-1}\ul{dg}]
=
-\ul{\vtheta}\wedge\ul{\vtheta}
\eeq


\qed

The Maurer-Cartan equation is intrinsic to the group, independent of the connection.

\subsection{Exp, Adj and adj maps}

In this section, we assume matrix representation of $G$.

For every $\vecX\in \ger{g}$ define
the {\bf exponential map} $\exp(\cdot)$ by

\beq
\exp: \ger{g}\rarrow G, \quad
g = \exp(\vecX) = 1 + \vecX + \frac{1}{2}(\vecX)^2 + \ldots
\eeq

Note that
\beq
g(\tau) = \exp(t \vecX)
\eeq
is a path in $G$. Since

\beq
e^{t_1 \vecX}e^{t_2\vecX}=
e^{(t_1+t_2)\vecX}
\eeq
this path is a subgroup of $G$.

For every $\vecX\in \ger{g}$, define
the {\bf large A adjoint  map} $\Ad()$ by

\beq
\Ad_g:\ger{g}\rarrow \ger{g}, \quad
\Ad_g \vecX = g\vecX g^{-1}
\eeq

For every $\vecX\in \ger{g}$, define
the {\bf small A adjoint map}  $\ad()$ by

\beq
\ad_\vecX:\ger{g}\rarrow \ger{g}, \quad
\ad_\vecX \vecY = [\vecY, \vecX]
\eeq


\begin{claim}

For any $n\times n$ matrices $A$ and $B$,

\beq
e^{A}B e^{-A}=
e^{[A,\cdot ]}B
\eeq

In particular, if $A=\vecX$
\beq
\Ad_{\exp\vecX}=
\exp(\ad_\vecX)
\eeq

\end{claim}
\proof

Define $M(t)$ by
\beq
M(t)=e^{tA}Be^{-tA}
\eeq

\beq
M(0)=B
\eeq

\beq
M'(t)= AM(t)- M(t)A= [A, M(t)]
\eeq
Think of $[A, \cdot]$ as an operator.
The clearly, this differential equation
and initial condition is satisfied 
by $M(t)=e^{t[A,\cdot]}B$. Now set $t=1$

\beq
e^{A}Be^{-A}= e^{t[A,\cdot]}B
\eeq

\qed

Connection with Maurer-Cartan form

Suppose 

\beq
g(t)= e^{t \vecX_e}
\eeq

Note that 
\beq
g^{-1}g'=\vecX_e
\eeq
Thus

\beq
\ul{\vtheta_g}(\vecX_g)=
g^{-1}\ul{dg}(\vecX_g) = g^{-1}g'=\vecX_e
\eeq

\subsection{Killing Fields}


\subsubsection{Derivatives along a path $\gamma$}

We call a function  $\gamma: [0, 1]\rarrow M$
a {\bf path or curve} on $M$.

We say {\bf  vector $\vecX$ is tangent to curve $\gamma$ } if

\beq
\vecX_{\gamma(\tau)}=\dotvec{\gamma}(\tau)
\eeq
for all  $\tau\in[0,1]$.
In such a case we will write
\beq
\vecX_{\gamma(\tau)} = \vecX^{\para \gamma}_{\gamma(\tau)}
\eeq
Suppose $\vecX$
is tangent to $\gamma(\cdot)$
but $\vecY$ is not so in general.
Then we define the {\bf covariant
derivative $\nnabla=D/d\tau$ 
along $\gamma$}  by

\beq
\frac{D\vecY_{\gamma(\tau)}}{d\tau}
=
\nnabla_{\vecX_{\gamma(\tau)}^{\para \gamma}}\vecY_{\gamma(\tau)}
\eeq
We will drop the $\gamma(\tau)$
subscripts  and write

\beq
\frac{D\vecY}{d\tau}=
\nnabla_{\vecX^{\para \gamma}}\vecY
\eeq
In a coordinate system,

\beq
\frac{D Y^\mu}{d\tau}
=
\frac{d Y^\mu}{d\tau}
+\Gamma\indices{^\mu_{\nu\rho}}
\dot{\gamma}^\nu
Y^\rho
\eeq
or, equivalently,

\beq
[\nnabla_{\vecX^{\para \gamma}}\vecY]^\mu
=
({\vecX^{\para \gamma}})^\nu \partial_\nu Y^\mu
+
\Gamma\indices{^\mu_{\nu\rho}}
[{\vecX^{\para \gamma}}]^\nu
Y^\rho
\eeq

{\bf Parallel transport along $\gamma$}  is simply

\beq
\nnabla_{\vecX^{\para \gamma}}\vecY=\frac{DY}{d\tau}=0
\eeq

\hrule
Consider a manifold $M$.

Define a {\bf path} to be a map

\beq
\gamma(\cdot:\pi):[0, 1]\rarrow M,
\quad \tau\mapsto \gamma(\tau;\pi)
\eeq
where $\pi\in M$  is a parameter of the function $\gamma(\cdot;\pi)$.
For example, $\tau$ might be time and point
$\pi=\gamma(0;\pi)$ might be the initial value
of $\gamma(\cdot;\pi)$.

Define a {\bf flow}  to be a map

\beq
\phi(\cdot:\tau):M \rarrow M,
\quad \pi\mapsto \gamma(\tau;\pi)
\eeq
where $\tau\in[0,1]$  is a parameter of the function $\phi(\cdot;\tau)$.
Thus, $\phi(\cdot;\tau)$ moves points
on the manifold $M$ and is parametrized by a \qt{time} $\tau\in[0,1]$.

Note that we can think of $\phi(\cdot;\tau)$ as being an $M$-slice (at fixed $\tau$)
and of $\gamma(\cdot;\pi)$
as being a $\tau$-slice (at fixed $\pi$)
of a surface
$\Phi:M\times [0,1]\rarrow M$
such that 

\beq
\Phi(\tau, \pi)=\gamma(\tau;\pi)=\phi(\tau;\pi)
\eeq

The Lie derivative $\call_\vecX$
can be defined in terms of pullbacks
a follows. Consider the action of 
$\call_\vecX$ on the metric function
$\metric(\vecU, \vecV)$ as an example.



\beq
\call_{\vecX_\pi}
\metric_\pi(\vecU_\pi \vecV_\pi)
=
\underbrace{\left(\AT{\frac{d}{d\tau}}{\tau=0}([\phi(\pi;\tau)]^*_\pi \metric_\pi)\right)}_{
\AT{\frac{d}{d\tau}}{\tau=0}(\phi(\pi;\tau)^*
\metric_\pi)}(\vecU_\pi \vecV_\pi)
=
\left[\AT{\frac{d}{d\tau}}{\tau=0}
\metric_{\gamma(\tau;\pi)}\right]
(\vecU_{\pi}
 \vecV_{\pi})
\eeq
where 
\beq
\phi(\pi;\tau=0)=\pi
\eeq

\beq
\vecX_{\gamma(\tau;\pi)}=\dotvec{\gamma}(\tau;\pi)
\eeq

A vector field $\vecX$ is said to be a {\bf Killing field of the metric $\metric$} if

\beq
\call_\vecX \metric=0
\eeq


\subsubsection{Examples of derivatives}
\begin{enumerate}
\item
\begin{claim}
Suppose $M=\RR^2$ with Euclidean metric
$
\metric=
(\ul{dx})^2 + (\ul{dy})^2$.
If

\beq
L_z = x\vecpder{y} -y\vecpder{x}=\begin{bmatrix}-y\\x\end{bmatrix}
\eeq
then 

\beq
\nnabla_\vecX L_z = 
\begin{bmatrix}
-X^2
\\
X^1
\end{bmatrix}
\eeq
\end{claim}
\proof

In this case the \Chris symbols are 
zero because the frame doesn't change
under parallel transport. Hence

\beq
\nnabla_\mu = \partial_\mu
\eeq

\beq
\nnabla_\vecX=
 X^1\begin{bmatrix}
0\\1
\end{bmatrix}
+
 X^2\begin{bmatrix}
-1\\0
\end{bmatrix}
=
\begin{bmatrix}
-X^2
\\
X^1
\end{bmatrix}
\eeq

\qed


\item

\begin{claim}
Suppose $M=\RR^2$ with Euclidean metric
\beq
\metric(\vecU, \vecV)=
\left[\ul{dx})^2 + (\ul{dy})^2\right
](\vecU, \vecV)= U^1V^1 + U^2V^2 =
\vecU^T \begin{bmatrix}1&0
\\
0&1\end{bmatrix}\vecV
\eeq
If

\beq
\vecX = y \vecpder{x}=\begin{bmatrix}y\\0\end{bmatrix}
\eeq
then 
\beq
\call_\vecX\metric = 2\ul{dx}\ul{dy}
\eeq
$\call_\vecX\metric\neq 0$ so 
$\vecX$ is not a Killing field.
This $\vecX$ is called a {\bf shear flow}.
The metric changes along a shear flow.
\end{claim}
\proof

First proof (from pullback definition):

If

\beq
\gamma(\tau;t)=
\begin{bmatrix}x+yt\\y\end{bmatrix}
\eeq
then
\beq 
\pi=\begin{bmatrix}x\\y\end{bmatrix},
\quad
 \vecX_\gamma = \dotvec{\gamma}
\eeq

\beq
\metric_\pi = (\ul{dx})^2  + (\ul{dy})^2,
\quad
\metric_{\gamma(\tau;\pi)} = (\ul{dx} + t\ul{dy})^2 
+ (\ul{dy})^2
\eeq

\beq
\call_\vecX \metric =
\AT{\frac{d}{dt}}{\tau=0}\metric_{\gamma(t)}
=2 \ul{dx}\ul{dy}
\eeq

Second proof (from formula):

\beqa
(\call_\vecX\metric)_{\mu\nu}
&=&
X^\lam \partial_\lam \metric_{\mu\nu}
+
\metric_{\lam\nu}
\partial_\mu X^\lam

\beq
(\nnabla_\vecX
\metric)(\vecU, \vecV)=
\oper{\vecX}
\metric(\vecU, \vecV)
-
\metric(\nnabla_\vecX \vecU, \vecV)
-
\metric(\vecU,
\nnabla_\vecX \vecV)
\eeq
We say there is 
{\bf metric 
compatibility}
if 
\beq
\nnabla \metric =0
\eeq
Metric compatibility 
implies
$\nnabla_\vecX\metric=0$ so

\beq
\oper{\vecX}\metric
(\vecU, \vecV)=
\metric(\nnabla_\vecX \vecU, \vecV)
+
\metric(\vecU,
\nnabla_\vecX \vecV)
\eeq
If we define $\vecX$ as being  
tangent to a path $\gamma:[0, 1]\rarrow M$, so that

\beq
\vecX^{\para \gamma}=\dotvec{\gamma}
\eeq
then

\beq
\frac{D\metric}{dt}=\nnabla_{\vecX}\metric=0
\eeq
and
\beq
\frac{d\metric}{dt}=\oper{\vecX}\metric
\eeq

\beq
\frac{d\metric}{dt}=
\metric(\nnabla_\vecX \vecU, \vecV)
+
\metric(\vecU,
\nnabla_\vecX \vecV)
\eeq
This is the reason 
this property is called 
metric compatibility (or zero 
metric covariant derivative)

\subsubsection{Torsion}

For a general affine connection (not necessarily
the Levi-Civita one to be discussed later), the {\bf torsion $T$}
is defined by

\beq
T(\vecX, \vecY)=
\nnabla_\vecX \vecY  -\nnabla_\vecY \vecX -
[\vecX, \vecY]
\eeq

\begin{claim}
In the coordinate basis,

\beq
T=0\quad \iff \quad
\Gamma\indices{^\rho_{\mu\nu}}
=
\Gamma\indices{^\rho_{\nu\mu}}
\eeq
\end{claim}
\proof
Set

\beq
\vecX = \vecpder{x^\mu}=\vecpartial_\mu,
\quad
\vecY=
\vecpder{x^\nu}=\vecpartial_\nu
\eeq
Then

\beq
T(\vecpartial_\mu,
\vecpartial_\nu)=
\nnabla_{\vecpartial_\mu}
\vec\partial_\nu
-
\nnabla_{\vecpartial_\nu}
\vecpartial_\mu
-
[
\vecpartial_\mu,
\vecpartial_\nu
]
\eeq

By the definition of
the \Chris symbols,

\beq
\nnabla_{\vecpartial_\mu}
\vecpartial_\nu = \Gamma\indices{^\rho_{\mu\nu}}\vecpartial_\rho
\eeq
and the same equation with $\mu\swap \nu$.

For the coordinate basis, 
the basis vectors commute
because partial
derivatives  commute.

\beq
[
\vecpartial_\mu,
\vecpartial_\nu
]=
[\partial_\mu, \partial_\nu]\vecr
=0
\eeq

Thus,

\beq
T(\vecpartial_\mu,
\vecpartial_\nu)=
\left(
\Gamma\indices{^\rho_{\mu\nu}}-
\Gamma\indices{^\rho_{\nu\mu}}
\right)\vecpartial_\rho
\eeq
\qed

The last 
claim is only valid
in the coordinate basis.
For a general basis (such
as Cartan orthonormal frames) $\vece_\mu$,

\beq
[\vece_\mu, \vece_\nu]\neq0
\eeq
Instead

\beq
[\vece_\mu, \vece_\nu]=
C\indices{^\rho_{\mu\nu}}\vece_\rho
\eeq
Then
\beq
T(\vece_\mu, \vece_\nu)=
[\Gamma\indices{^\rho_{\mu\nu}}
-
\Gamma\indices{^\rho_{\nu\mu}}]\vece_\rho
-
[\vece_\mu, \vece_\nu]
\eeq
so


\beq
T\indices{^\rho_{\mu\nu}}=
\Gamma\indices{^\rho_{\mu\nu}}
-
\Gamma\indices{^\rho_{\nu\mu}}
-
C\indices{^\rho_{\mu\nu}}
\eeq


\beq
T=0\quad \iff
\quad 
\Gamma\indices{^\rho_{\mu\nu}}
-
\Gamma\indices{^\rho_{\nu\mu}}
=
C\indices{^\rho_{\mu\nu}}
\eeq

In Cartan's theory,

\beq
\pform{T^a}{2} = \pform{d\theta^a}{2} + \pform{\omega\indices{^a_b}}{}\wedge \pform{\theta^b}{}
\eeq
When $\ul{\theta^a} =\ul{dx^a}$, the 
term $\ul{d\theta^a}$
vanishes.


\subsubsection{
Levi-Civita connection}


For the {\bf Levi-Civita  connection (LCC) $\nnabla$},
\begin{enumerate}
\item  
The metric is constant
under parallel transport.  This situation
is also referred to as 
{\bf metric compatibility of the connection}
\beq
 \nnabla_\lam\metric_{\mu\nu}=0
\eeq
\item the torsion is zero

\beq 
T\indices{^\lam_{\mu\nu}}=0
\eeq
\end{enumerate}

If

\beq
[\nnabla_{\vecpartial_\mu}
\vecpartial_\nu]^\rho=
\Gamma\indices{^\rho_{\mu\nu}}
\eeq
then

\beq
T\indices{^\lam_{\mu\nu}}=0
\quad
\text{ iff }\quad
\Gamma\indices{^\rho_{\mu\nu}}
=
\Gamma\indices{^\rho_{\nu\mu}}
\eeq
For LCC,

\beq
[\nnabla_\vecX Y]^\rho=
X^\mu \partial_\mu Y^\rho
+\Gamma\indices{^\rho_{\mu\nu}}
X^\mu
Y^\nu 
\eeq

\begin{claim}
For a { general affine connection $\nnabla$}, in the coordinate basis\footnote{Note that we will
use the terms \qt{connection} and \qt{covariant derivative} and the symbol $\nnabla$ as synonymous.
Some people reserve the term \qt{connection} and the symbol $\nnabla$ for the
operator (linear map) and \qt{covariant derivative} for the image elements of that map, but it's a minor distinction we won't make.}

\beq
[\call_\vecX \metric]_{\mu\nu}
= 
X^\lam \nnabla_\lam\metric_{\mu\nu}+
\nnabla_\mu X_\nu+
\nnabla_\nu X_\mu
+
X^\lam\left[T_{\lam\mu\nu} + (\mu\swap \nu)\right]
\eeq
where $T_{\lam \mu\nu}$ represents
the torsion tensor with the $\lam$
index lowered appropriately.
\end{claim}
\proof

The coordinate-free
definition is
\beq
(\call_\vecX \metric)
(\vecU, \vecV)
=
\vecX[\metric(\vecU, \vecV)]
-
\metric([\vecX, \vecU], \vecV)
-
\metric(\vecU,
[\vecX, \vecV])
\eeq

\beq
\vecX[\metric(\vecU, \vecV)]
=
(\nnabla_\vecX\metric)(\vecU, \vecV)
+
\metric)(
\nnabla_\vecX
\vecU, \vecV)
+
\metric)(\vecU, 
\nnabla_\vecX
\vecV)
\eeq

\beq
[\vecX, \vecY]=
\nnabla_\vecX\vecY
-
\nnabla_\vecY \vecX 
-
T(\vecX, \vecY)
\eeq
for $\vecY = \vecU, \vecV$.
Substituting, we get

\beq
(\call_\vecX)
(\vecU, \vecV)
=
\left\{
\begin{array}{l}
(\nnabla_\vecX\metric)
(\vecU, \vecV)
\\
+
\metric
(\nnabla_\vecU
\vecX, \vecV)
+
\metric
(\vecU, 
\nnabla_\vecV
\vecX)
\\
+
\metric
(T(\vecX,\vecU), \vecV)
+
\metric
(\vecU, 
T(\vecX,\vecV))
\end{array}
\right.
\eeq
Now replace

\beq
\vecU=\vecpartial_\mu,
\quad \vecV=\vecpartial_\nu,
\quad
\vecX = X^\lam \vecpartial_\lam
\eeq


\beq
\nnabla_\vecU\vecX=
 \vecpartial_\lam\nnabla_\mu X^\lam
\eeq

\beq
\quad
\metric
(\nnabla_\vecU
\vecX, \vecV)=
\metric_{\lam\nu}
\nnabla_\mu X^\lam=
\nnabla_\mu X_\nu
\eeq

\beq
T(\vecX, \vecU)=
X^\lam T\indices{^\rho_{\lam\mu}}
\vecpartial_\rho
\eeq

\beq
\metric(T(\vecX, \vecU), \vecV)=
X^\lam T\indices{^\rho_{\lam\mu}}
 \metric_{\rho\nu}
=X^\lam T_{\nu\lam\mu}
\eeq
\qed

For the LLC, the Lie derivative takes this simple form in the coordinate basis,

\beq
[\call_\vecX 
\metric]_{\mu\nu}= \nnabla_\mu X_\nu 
+ (\mu\swap \nu)
\eeq
and the Killing fields satisfy

\beq
0=
[\call_\vecX 
\metric]_{\mu\nu}= 
\nnabla_\mu X_\nu 
+ (\mu\swap \nu)
\eeq
\subsubsection{Lie Derivative of general tensor in LCC}\label{sec-Lie-der-tensor}
The following
is valid for LCC 
with possibly a non-\Rien metric.
Specifically, the
following is valid for General
Relativity which is torsion
free and has a pseudo-\Rien
metric (i.e., one with 
one or more negative eigenvalues)

\begin{claim}

\beq
(\call_\vecX  \vecY)=
X^\mu \nnabla_\mu
Y^\nu -
Y^\mu \nnabla_\mu X^\nu
\eeq


\end{claim}
\proof
\beq
\call_\vecX \vecY=
[\oper{\vecX}, \oper{\vecY}]\vecr
\eeq

\beq
\vecX = X^\mu \vecpartial_\mu,\quad
\vecY = Y^\nu \vecpartial_\nu
\eeq

\beqa
[\oper{\vecX}, \oper{\vecY}]\vecr
&=&
X^\mu\partial_\mu
Y^\nu\partial_\nu\vecr
-
(X\swap Y)
\\
&=&
X^\mu\partial_\mu
Y^\nu-
(X\swap Y)
\eeqa

Next, we replace 
the partial derivatives
by covariant ones because the \Chris symbols
cancel.

\beq
\nnabla_\mu V^\nu=
\partial_\mu V^\nu
+
\Gamma\indices{^\nu_{\mu_\lam}}V^\lam
\eeq
for $V=X, Y$


\beq
X^\mu\Gamma\indices{^\nu_{\mu\lam}}Y^\lam
-
(X\swap Y)=0
\eeq
because

\beq
\Gamma\indices{^\nu_{\mu\lam}} = 
\Gamma\indices{^\nu_{\lam\mu}}
\eeq
The \Chris symbols are symmetric
in $mu, \lam$ because the torsion
is assumed to be zero.

\qed

\beq
\ul{\omega}=\omega_\nu \ul{dx^\nu}
\eeq

\beq

\beq

+

\beq

\partial_\mu \omega_\nu -
\Gamma\indices{^\lam_{\mu\nu}}\omega_\lam
\eeq

\nnabla_\nu X^\mu=
\partial_\nu X^\mu +
\Gamma\indices{^\mu_{\nu\lam}}X^\lam
\eeq


\beq
-X^\mu \Gamma\indices{^\lam_{\mu\nu}}\omega_\lam
+
\omega_\mu
\Gamma\indices{^\mu_{\nu\lam}}X^\lam

\eeq
