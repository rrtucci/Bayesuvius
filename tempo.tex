\subsection{Posets}

A {\bf partial order set or poset}
$(P, \pord )$
consists of a set $P$ on which a relation $\pord $ is defined. For all $a,b,c\in P$, the  relation must 
satisfy:

\begin{enumerate}
\item
{\bf reflexivity:}
$a\pord  a$

\item 
{\bf antisymmetry:}
if $a\pord  b$ and $b\pord  a$ then $a=b$.

\item{\bf transitivity:}
if $a\pord  b$ and $b\pord  c$ then $a\pord  c$.

Given a general poset $(P, \pord)$ with two elements $a, b\in P$,
if we cannot find a path of $a\pord x_1 \pord x_2\pord\ldots\pord b$,
or a path connecting $a$ and $b$  in the other direction,  then we say $a$ and $b$ are {\bf non-comparable}.
General posets can have
non-comparable elements.
A {\bf total order} is a poset
in which all elements are comparable.

\end{enumerate}

A {strict poset} $(P, \spord )$
consists of a set $P$ on which a relation $\spord $ is defined. For all $a,b,c\in P$, the  relation must 
satisfy:

\begin{enumerate}
\item
{\bf anti reflexivity:}
No element $a\in P$ satisfies $a\spord  a$

\item 
{\bf antisymmetry:}
if $a\spord b$ then
not  $b\spord a$

\item{\bf transitivity:}
if $a\spord  b$ and $b\spord  c$ then $a\spord  c$

\end{enumerate}

A {\bf logic matrix} 
for a poset $(P,  \pord )$ is a matrix $M$ such that

\beq
M_{ab} =\indi(a \pord  b)
\eeq
for all $a, b\in P$.

3 types of similar diagrams that can be used to represent a poset:

\begin{enumerate}

\item A {\bf DAG} is a directed acyclic graph. It represents a bnet. 

In a DAG, we say an {\bf arrow 
$\rvx\rarrow \rvy$ is transitive}  if there is a node $\rvm$ \qt{in between} $\rvx$ and $\rvy$ ;i.e.,  if there is 
a node $\rvm$ and arrows $\rvx\rarrow \rvm$, $\rvm\rarrow \rvy$.
A DAG can be used to represent a 
poset but not all DAGs represent a poset. That's because a DAG can contain some
but not all of the transitive arrows whereas poset is normally represented by a DAG with no transitive arrows although one  could say the transitive arrows are implicit.

\item A {\bf Hasse diagram} is a minimal representation of a poset.
By this we mean that 
it contains an arrow $\rva\larrow \rvb$ iff $\rva \pord \rvb$ and there is no 
$\rvx$ such that $\rva\pord \rvx\pord \rvb$.
Hence, a Hasse diagram is a DAG 
without any transitive arrows

\item A {\bf lattice} is a poset $(P, \pord)$ equipped with two binary operations $\A$ and $\V$, such that, for every pair $a, b\in P$, 

\begin{enumerate}
\item there exists a unique {\bf supremum (sup)} (a.k.a join)
denoted by $a\A b$.
By a supremum, we mean an element $sup\in P$ 
which satisfies

\beq
a\pord sup, \quad b\pord sup
\eeq
and is the largest element
of $P$ to do so.


\item there is  a unique
{\bf infimum (inf)}, or the {meet} denoted by $a\V b$.

By an infimum, we mean an element $inf\in P$ 
which satisfies

\beq
inf \pord a, \quad inf\pord b
\eeq
and is the smallest element
of $P$ to do so.
\end{enumerate}

\beq
a\pord (a \A b) , \quad b\pord (a \A b)
\eeq


\begin{claim}
$\pord$ is defined
in terms of $\V$ and $\A$ by  either

\beq
a\pord b \iff a\A b =b
\eeq
or, equivalently,

\beq
a\pord b \iff a \V b =a
\eeq
\end{claim}
\proof
\qed

Thus, a lattice
is a special type of poset.
Whereas a general poset can have
a pair of non-comparable elements, 
all the elements of a lattice are comparable, because
the relation $\pord$ is defined
for every pair of elements $a, b$ in terms of $\A$ or $\V$.


 



\end{enumerate}
